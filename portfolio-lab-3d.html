สร้าง Portfolio หนึ่งหน้า ด้วย HTML และ CSS

หมุนดูหน้าเว็บที่ถูกแยกออกเป็นชั้นตามโครงสร้างแท็ก คลิกแต่ละชั้นเพื่อดูหน้าที่และโค้ด สลับดูผลก่อนและหลังใส่ CSS แล้วลองเปลี่ยนสีหลักของเว็บได้ทันที

ลากเพื่อหมุน · ซูมด้วยล้อเมาส์หรือสองนิ้ว · คลิกชั้นเพื่อดูรายละเอียด
Elementsstyled

    ขั้นตอนการทำ

    กิจกรรมนี้ฝึกสร้างเว็บไซต์ส่วนตัวหนึ่งหน้า ตั้งแต่สร้างไฟล์ เขียนเนื้อหา เพิ่มภาพ จัดรูปแบบ และทดสอบในเบราว์เซอร์ เมื่อทำครบจะได้เว็บที่มีเมนู ประวัติ ผลงาน และช่องทางติดต่อ โดยเปิดดูจากเครื่องของตนเองได้

    1

    เตรียมไฟล์และรูปภาพ

    เปิด VS Code เลือก File → Open Folder แล้วเปิดโฟลเดอร์ใหม่ชื่อ my-portfolio สร้างไฟล์และจัดวางรูปภาพดังนี้

    index.htmlโครงสร้างและเนื้อหาเว็บไซต์
    style.cssสี ขนาด และการจัดวาง
    img/profile.jpgรูปประจำตัว
    img/work1.jpgภาพผลงาน

    ตรวจนามสกุลภาพให้ตรงกับโค้ด หากภาพเป็น .png ให้เปลี่ยนตำแหน่งภาพใน src เป็น .png ด้วย ระวังการบันทึกไฟล์เป็น index.html.txt

    2

    ทดลองเปิดหน้าเว็บแรก

    พิมพ์โค้ดนี้ใน index.html บันทึก แล้วดับเบิลคลิกไฟล์จากโฟลเดอร์เพื่อเปิดในเบราว์เซอร์

    ทดลองเปลี่ยนข้อความใน h1 เป็นชื่อตนเอง แล้วทำตามลำดับนี้ทุกครั้ง

    แก้โค้ด→บันทึก→รีเฟรช→ดูผล
    3

    สร้างเนื้อหา Portfolio

    แทนที่โค้ดเดิมใน index.html ด้วยโค้ดสองส่วนนี้ตามลำดับ ทั้งสองส่วนเป็นไฟล์เดียวกัน แล้วเปลี่ยนข้อมูลให้เป็นของตนเอง

    จุดสังเกต href="#about" เชื่อมกับ id="about" จึงใช้เมนูเลื่อนไปยังหัวข้อภายในหน้าเดียวกันได้

    ต่อโค้ดด้านล่างทันทีหลัง </section> ของส่วนเกี่ยวกับฉัน ห้ามเพิ่มโครงสร้าง html หรือ body ซ้ำ

    ตรวจผลหลังเขียน HTML บันทึกไฟล์แล้วรีเฟรช ต้องเห็นชื่อ ประวัติ รูปประจำตัว และภาพผลงาน คลิกเมนูผลงานแล้วหน้าเว็บควรเลื่อนถึงหัวข้อผลงาน ช่วงนี้หน้าตายังเรียบง่ายเพราะยังไม่ได้เพิ่ม CSS (กดปุ่ม HTML ล้วน ในโมเดลด้านบนเพื่อดูหน้าตาช่วงนี้)

    ลิงก์ mailto ขอเปิดแอปอีเมลที่ตั้งค่าไว้ ไม่ได้ส่งอีเมลอัตโนมัติ ให้เปลี่ยนที่อยู่อีเมลตัวอย่างเป็นที่อยู่จริงก่อนใช้งาน หากต้องการแบบฟอร์มส่งข้อความจริงต้องเชื่อมระบบรับข้อมูลเพิ่มเติม

    หน้าที่ของแท็กที่ใช้ คลิกแถวเพื่อดูชั้นนั้นในโมเดล 3 มิติ

    แท็กหรือคุณสมบัติหน้าที่
    header และ navส่วนหัวและเมนูนำทาง
    main และ sectionเนื้อหาหลักและส่วนตามหัวข้อ
    h1 ถึง h3 และ pหัวเรื่อง หัวข้อย่อย และย่อหน้า
    img และ srcแสดงภาพและระบุตำแหน่งไฟล์ภาพ
    altข้อความทดแทนที่อธิบายภาพ
    figure และ figcaptionจัดกลุ่มภาพและคำอธิบาย
    footerส่วนท้ายของหน้าเว็บ
    4

    เพิ่ม CSS ให้เว็บ

    สร้าง style.css ข้าง index.html ใส่โค้ดนี้ บันทึก แล้วรีเฟรช จะเห็นพื้นหลัง เมนู และกล่องเนื้อหา

    ทดลองเปลี่ยน #173b73 เป็น #6d28d9 ทั้งสองตำแหน่ง แล้วสังเกตสีของส่วนหัวและปุ่ม ลองกดสีม่วงที่แถบเครื่องมือของโมเดลด้านบนเพื่อดูผลก่อนแก้จริง
